# Capturas de evidencia

Cada reto referencia sus capturas en `retoNN/`. Mientras el archivo no exista,
la app muestra un hueco naranja con la ruta esperada.

Para rellenar: pega tu screenshot con el nombre exacto que pide la app, p. ej.
`reto01/01-fuente-credenciales.png`. No subir datos personales de terceros ni
flags/seriales completos si el profe pide no divulgarlos.
